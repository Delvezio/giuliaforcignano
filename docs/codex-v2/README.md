# Evoluzione giuliaforcignano.it — pacchetto Codex

Questo pacchetto raccoglie in forma pronta all’uso le istruzioni tecniche e i contenuti per evolvere il sito di Giulia Forcignanò senza alterarne l’identità visiva.

## File inclusi

- `ISTRUZIONI.md` — come preparare il repository, avviare Codex e controllare il lavoro.
- `PROMPT_CODEX.md` — prompt operativo da consegnare a Codex.
- `CONTENT_SPEC.md` — fonte autoritativa per testi, percorsi, CTA, SEO e microcopy.
- `CHECKLIST_FINALE.md` — controlli tecnici, editoriali, responsive, privacy e accessibilità.

## Ordine consigliato

1. Apri in Codex la cartella del repository di `giuliaforcignano.it`.
2. Aggiungi al repository i quattro file di questo pacchetto, preferibilmente in `docs/codex-v2/`.
3. Apri una nuova sessione Codex e incolla integralmente `PROMPT_CODEX.md`.
4. Chiedi a Codex di leggere `CONTENT_SPEC.md` e `CHECKLIST_FINALE.md` prima di modificare il codice.
5. Lascia che analizzi il progetto, implementi e verifichi build, lint, type-check e test disponibili.
6. Controlla manualmente il risultato prima del deploy e fai validare a Giulia le pagine degli ambiti.

## Regola essenziale

`CONTENT_SPEC.md` è la fonte testuale autoritativa. Codex può adattare soltanto punteggiatura o markup indispensabili all’integrazione tecnica, senza riscrivere il copy e senza inventare dati professionali.
